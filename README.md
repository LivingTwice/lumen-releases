# Lumen releases have moved

**Lumen now lives at [github.com/LivingTwice/lumen](https://github.com/LivingTwice/lumen)**: its source code and every new version.

**[Download the latest version](https://github.com/LivingTwice/lumen/releases/latest)** for Mac (Apple silicon) or Windows 10 and 11.

This repository keeps the older versions (0.1.0 to 0.7.0) and the dictionaries they download. It also forwards installed copies of Lumen to each new version: **if you already use Lumen, there is nothing to do**, the update is offered in the app.
